# 콘텐츠 리포트 스택

콘텐츠 산업 관련 기관·연구소가 발간하는 리포트와 포럼·컨퍼런스 발제자료를
매주 수요일 정리해 쌓는 페이지입니다.

**보기 →** https://kwannnnnnnnnn.github.io/contents-report/

- 최근 4주 수집분은 수집 주차별 표, 그 이전은 장르별 표로 정리됩니다.
- 표 상단에서 제목·기관·발표자·내용·태그를 한 번에 검색할 수 있습니다.
- 행을 클릭하면 상세 요약과 발표자 명단이 펼쳐집니다.

리포트 원문은 이 저장소에 없습니다. 각 리포트의 저작권은 발행기관에 있으며,
이 페이지는 출처를 밝힌 요약과 원문 페이지 링크만 제공합니다.
